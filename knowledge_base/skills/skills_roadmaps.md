# Technical Skills Roadmaps & Recommended Learning Resources

## Frontend Development Skills
### React.js / Next.js
- **Key Concepts**: JSX, Hooks (useState, useEffect, useMemo), Context API, Component Architecture, SSR/SSG.
- **Recommended Free Resources**:
  - React Official Documentation (react.dev)
  - FreeCodeCamp - React Full Course
- **Practice Projects**: Interactive Dashboard, E-commerce Storefront, Real-time Chat App.

### TypeScript
- **Key Concepts**: Static Types, Interfaces, Generics, Type Inference, Utility Types, Async/Await with Types.
- **Recommended Free Resources**:
  - TypeScript Handbook (typescriptlang.org)
  - ExecuteProgram - TypeScript Basics
- **Practice Projects**: Strongly typed REST API client, Custom UI Component Library.

## Backend Development Skills
### Python & FastAPI
- **Key Concepts**: Async IO, Pydantic Schemas, Dependency Injection, SQLAlchemy ORM, JWT Auth.
- **Recommended Free Resources**:
  - FastAPI Official Tutorial (fastapi.tiangolo.com)
  - Python Docs - Advanced Asyncio
- **Practice Projects**: RESTful Microservice, Document Processing Pipeline.

### Node.js & Express
- **Key Concepts**: Event Loop, Middleware, Express Routing, Async Promises, JWT Auth, Database Integration.
- **Recommended Free Resources**:
  - Node.js Documentation (nodejs.org)
  - MDN Express Web Development Guide
- **Practice Projects**: User Authentication Microservice, Real-time Socket.io API.

## Database & Cloud Skills
### PostgreSQL & SQL
- **Key Concepts**: Relational Schema Design, Foreign Keys, Indexes, JOIN Operations, Transactions, Aggregations.
- **Recommended Free Resources**:
  - Postgres Tutorial (postgresqltutorial.com)
  - SQLBolt - Interactive SQL Lessons
- **Practice Projects**: Database Schema Optimization, Analytics Aggregation Queries.

### Docker & Containerization
- **Key Concepts**: Dockerfile Creation, Image Layers, Container Networking, Volumes, Docker Compose Multi-container Setup.
- **Recommended Free Resources**:
  - Docker Official Getting Started Guide
  - FreeCodeCamp - Docker for Beginners
- **Practice Projects**: Containerizing Full-Stack App (Frontend + Backend + PostgreSQL).

### AWS & Cloud Infrastructure
- **Key Concepts**: EC2, S3 Storage, IAM Roles, Lambda Serverless Functions, CloudWatch Logging.
- **Recommended Free Resources**:
  - AWS Educate & Free Tier Documentation
  - AWS Certified Cloud Practitioner Roadmaps
- **Practice Projects**: Host Static Website on S3 + Deploy FastAPI backend on EC2 with Nginx.
